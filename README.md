# 🎬 MeshalClip

**Download videos from social media in one place.**

MeshalClip is a Windows application for downloading videos from supported social media platforms, powered by [yt-dlp](https://github.com/yt-dlp/yt-dlp).

## ✨ Features

- 📥 Download videos from supported platforms.
- 🚫 Watermark-free downloads where supported.
- 🖥️ Windows desktop application.
- ⚡ Simple and convenient interface.
- 🔗 Powered by yt-dlp.

## 📋 Requirements

- 🪟 Windows 10 or Windows 11
